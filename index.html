About

A showcase, not a slide deck.

DuoOps exists to show a DevOps loop actually working — source control feeding continuous integration, a build getting containerized, a deploy landing somewhere real, and monitoring watching all of it happen.

It's built by two people rather than one, on purpose: one working closer to the application and security side, the other closer to delivery and documentation, meeting in the middle at the pipeline itself.

The pipeline

Four stages, commit to watch — built on GitHub, Docker, and AWS.

01
Source & CI

Commit → build → test on GitHub

Code lives on GitHub, with a GitHub Actions workflow triggered on push — building the project and running tests before anything moves to the next stage.

GitHubGitHub ActionsAutomated tests
02
Containerize

Package the build with Docker

A passing build gets packaged into a Docker image — a consistent, portable unit that runs the same way locally as it does once deployed.

DockerDockerfileImage registry
03
Deploy

The container is deployed to AWS — CLoud Formation for the server deployment, however that gets triggered from the pipeline.
